# Omalookout

AIS targets and collision alarms for [Omahoy](https://github.com/shieldsworks/omahoy).

**Status: planned.** Nothing to install yet.

## What it will do

- List every vessel in range, with each one's closest point of approach and the
  time until it.
- Sound collision alarms at thresholds you set.
- Show the nearest vessel in a bar widget.
- Decode AIS messages itself, from a dAISy receiver through
  [omakeel](https://github.com/shieldsworks/omakeel). A software-radio receiver for
  RTL-SDR is a stretch goal.
